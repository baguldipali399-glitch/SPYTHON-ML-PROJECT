# SPYTHON - Smart E-Commerce Intelligence System

This project was completed as part of the SPYTHON: Rise of the Machine Learning workshop conducted by the Fetch.ai Developer Club.

## Project Objective

The project uses Machine Learning to analyze e-commerce customer behavior and:

- Predict annual customer spending
- Predict customer churn

## Machine Learning Models

### Regression
- Linear Regression
- Decision Tree
- Random Forest

### Classification
- Logistic Regression
- Decision Tree
- Random Forest
